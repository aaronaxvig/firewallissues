## PANG-9242

Fixed an issue where DNS resolution failed when the Prisma Agent was connected on Linux devices. The agent now maintains DNS resolution functionality when connected.

## PANG-8945

Fixed an issue on Linux endpoints where the Prisma Agent system tray icon disappeared after the user's display went to sleep and then woke up. This occurred because the system tray application exited when the display went to sleep, and did not restart when the display woke up.

The system tray icon now remains present after the display wakes from sleep.

## PANG-8929

Fixed an issue on Linux endpoints where the Prisma Agent failed to connect when the agent was enrolled but the user had not yet completed sign-in. The agent now successfully connects in this scenario.
