## PANG-15145

Fixed an issue on macOS endpoints where the Prisma Agent cycled through all available gateways without connecting after a portal switch. The agent now correctly establishes a tunnel after switching portals.

## PANG-15111

Fixed an issue on Windows endpoints where the Prisma Agent became stuck in the Connecting state after waking from modern standby. The agent now correctly resumes connectivity after wake.

## PANG-15030

Fixed an issue on Windows endpoints where HIP submission failed after upgrading if a previous OPSWAT update had installed a newer version of the HIP compliance libraries than the version bundled with the upgrade. HIP compliance checks now succeed after upgrade.

## PANG-14967

Fixed an issue on Windows endpoints where network connectivity was lost after the Prisma Agent established an IPsec tunnel. Split-DNS queries failed because the agent used the tunnel's virtual IP address as the source before it was fully configured on the network adapter. The agent now waits for the virtual adapter address to be ready before signaling tunnel connectivity.

## PANG-14924

Fixed an issue on macOS endpoints where users were unable to establish a tunnel after clicking Login when SAML authentication was required. The Prisma Agent now correctly establishes the tunnel after SAML authentication.
