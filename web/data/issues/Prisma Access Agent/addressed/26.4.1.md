## PANG-14811

Fixed an issue on macOS endpoints where Cisco AnyConnect VPN's secondary UDP/DTLS 1.2 tunnel was terminated shortly after being established when Prisma Agent was installed and disabled or you were signed out. The primary TLS-based TCP tunnel was not affected.

## PANG-14481

Fixed an issue on macOS endpoints where the HIP report did not include CrowdStrike Falcon's definition version. HIP policies that required a valid CrowdStrike Falcon definition version failed, which could deny or restrict network access even when CrowdStrike was installed and up to date.
