## PAN-337475

(PA-5440 firewalls only) Fixed an issue where SaaS applications were incorrectly blocked even when a higher-order security rule should have allowed the traffic, which occurred due to an unexpected policy rematch behavior. With this fix, security policy rules are correctly applied during policy rematch, ensuring expected traffic flow.

## PAN-333108

Fixed an issue where device telemetry uploads would fail, which led to critical alerts in the system logs. With this fix, telemetry data uploads complete successfully.

## PAN-329809

Fixed an issue where testing an SCP server connection from the Panorama web interface returned an error instead of prompting to allow the host key, which prevented the successful establishment of the connection. With this fix, the system now correctly prompts to allow the host key.

## PAN-329511

(PA-4xx Firewalls) Fixed an issue where firewalls rebooted unexpectedly after an upgrade. With this fix, firewalls now operate stably after an upgrade.

## PAN-324684

Fixed an issue where Panorama would change service routes configured with Loopback interfaces in templates to "Any" after an upgrade to PAN-OS 12.1.3, particularly when importing a new device. With this fix, Panorama preserves Loopback interface assignments within template configurations.

## PAN-313850

```caveat
PA-1400 Series firewalls in HA configurations only
```

Fixed an issue where a split-brain condition occurred and HA1/HA2 links went down while upgrading when the HA configuration used dataplane interfaces for HA1 and a combination of HSCI and Ethernet interfaces for HA2.

## PAN-307491

Fixed an issue where the firewall entered maintenance mode after a reboot when ZTP was enabled.
