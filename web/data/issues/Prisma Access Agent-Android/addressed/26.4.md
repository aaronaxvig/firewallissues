## PANG-14997

Fixed an issue on Android endpoints where HIP report traffic was routed through the physical network interface instead of through the VPN tunnel. On deployments using a Network Load Balancer (NLB), this caused HIP report submissions to time out because the in-tunnel gateway IP was unreachable from the physical interface. HIP report submissions and logout API requests are now routed through the VPN tunnel.
