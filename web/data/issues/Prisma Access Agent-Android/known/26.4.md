## PANG-15590

On Chrome OS endpoints, system notifications are not delivered when the Prisma Agent window is unfocused. An unfocused app window should behave the same as a backgrounded app and deliver system notifications.

## PANG-15552

On Android endpoints, when you enter an incorrect endpoint management portal address, the Prisma Agent app displays "Failed to enroll error: Failed to resolve <epm_domain>" instead of "Please check your network connection and ensure the server address is correct."

## PANG-15514

On Android endpoints, sign-in notifications are received even when the notification setting is disabled, when LDAP authentication is configured.

## PANG-15405

On Android endpoints, when the Prisma Agent connects to a gateway over an IPv6 underlay, the gateway reports the client's public IP address as 0.0.0.0 and the source region as empty.

## PANG-15404

On Android endpoints, when the gateway is reached over an IPv6 underlay, IPSec tunnel establishment times out and the Prisma Agent app falls back to SSL VPN. SSL VPN then connects successfully.

## PANG-15131

On Android endpoints connected to a Prisma Access gateway behind a Network Load Balancer (NLB), the IP address in the Prisma Agent app's Settings screen displays as 127.127.127.127 instead of the actual gateway IP address.

## PANG-14998

On Android endpoints, after the Prisma Agent disconnects, the gateway continues to show the user session as active. The agent continues sending keepalive messages while in a disconnected state, which prevents the gateway from terminating the session.
