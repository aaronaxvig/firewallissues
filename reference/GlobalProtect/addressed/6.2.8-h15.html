GPC-27851
Fixed an issue where GlobalProtect could not connect after an upgrade, which occurred because the GlobalProtect service sent portal configuration and gateway authentication requests to the portal's connected IP address instead of its fully qualified domain name (FQDN), causing certificate verification to not succeed. Users encountered the error "The network connection is unreachable or the gateway is unresponsive. Check the network connection and reconnect." With this fix, GlobalProtect correctly routes requests to the portal FQDN and connects as expected.
GPC-27846
(macOS devices) Fixed an issue where GlobalProtect authentication did not complete during the portal sign-in process, which caused users to encounter an "Authentication Failed" error. This occurred because the GlobalProtect service stopped unexpectedly during SAML authentication. With this fix, GlobalProtect authenticates and connects as expected.
GPC-27555

With this fix, GlobalProtect connections now refresh as expected without interruption.
