PAN-335982
[PA-56R-POE-5G only] Fixed an issue where Power over Ethernet (PoE) ports did not correctly reflect their operational state during thermal throttling events, which led to a discrepancy where the ports appeared disabled in some system reports while remaining active according to their configuration. With this fix, PoE ports accurately reflect their operational state during thermal throttling.
PAN-335793
(PA-54R-POE, PA-54R-POE-D-5G, and PA-56R-POE-5G firewalls only) Fixed an issue where the user interface displayed a Power over Ethernet (PoE) budget of 150W, instead of the actual limit of 91W, which occurred because the user interface did not correctly retrieve the platform's Power over Ethernet (PoE) budget limit. With this fix, the user interface now accurately reflects the correct Power over Ethernet (PoE) budget.
PAN-335306
Fixed an issue where syslog server connections would remain in an ESTABLISHED state after a commit operation when syslog forwarding was configured using TCP, which indicated a connection socket leak. With this fix, connections are properly closed.
PAN-334757
(RN-HP firewalls only) Fixed an issue where packet buffer resources would leak during a temporary surge in packet buffer usage, which caused tunnels to become unavailable. With this fix, packet buffer resources are managed correctly during periods of high usage.
PAN-334722
Fixed an issue where the firewall introduced out-of-order packet delivery for certain data streams, which resulted in clients receiving data in an incorrect sequence.
PAN-334616
(M-700 Panorama appliances only) Fixed an issue where the system was unable to add new RAID disks to existing arrays, which resulted in disk pairs remaining in a degraded state. The system would detect the drives but would not properly initialize them for inclusion in the RAID array. With this fix, the system now correctly initializes and adds new RAID disks, allowing for proper array rebuilds.
PAN-334304
Few configs which pushed from SCM to firewall were causing the firewall to loose its internet connectivity and the firewall wasn't able to connect to cloud and was getting stuck at discovery stage retrying indefinitely without returning failure. And now ACR performs the the config rollback once the 5 cloud connectivity check attempts failed.
PAN-333304
[PA-54R-POE-D-5G and PA-54R-POE only] Fixed an issue where the Vehicle Interface Management System (VIMS) could be enabled when the firewall was connected to a Low Voltage Power Supply Unit (LVPSU) or High Voltage Power Supply Unit (HVPSU), which led to unsupported system behavior. With this fix, the system prevents VIMS from being enabled under these conditions.

With this fix, firewalls transition to a clustered state as expected.
