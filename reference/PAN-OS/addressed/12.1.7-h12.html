Fixes were made to address the following CVEs:
  • CVE-2026-0331
  • CVE-2026-0330
  • CVE-2026-0329
  • CVE-2026-0328
PAN-341570
Fixed an issue where NAT64 client-to-server (c2s) packet IP addresses were corrupted during 6-to-4 translation after hardware offload.
PAN-341332
Fixed an issue where selectively disabling offload for filtered traffic did not function as expected, and sessions continued to be offloaded. With this fix, offload is correctly disabled for filtered traffic.
PAN-341207
(PA-7500 firewalls only) Fixed an issue where NAT64 server-to-client traffic failed on sessions using hardware session offload, causing the firewall to translate the destination port incorrectly after a session was offloaded and resetting the connection. With this fix, NAT64 translates server-to-client traffic correctly on sessions using hardware session offload.
PAN-339281
Fixed an issue where Anti-virus content packages do not appear under Device > Dynamic Updates when you select Check Now on firewalls licensed exclusively with an Advanced Threat Prevention Plus add-on. The web interface does not check for or display available Anti-virus updates because it does not recognize the Advanced Threat Prevention Plus license as a valid entitlement for Anti-virus content.
PAN-338501
(PA-5540 firewalls only) Fixed an issue where BGP, BFD, and OSPF peering sessions became unavailable on the firewall and later restored. With this fix, peering sessions no longer experienced unexpected interruptions.
PAN-335567
(Panorama appliances only) Fixed an issue where tracebacks appeared in the raid.log file, accompanied by messages indicating that a redundant array of independent disks (RAID) pair had disappeared. This occurred due to an internal processing error when handling RAID device paths during system boot, which could lead to incorrect reporting of RAID status. With this fix, the system correctly processes RAID device paths, preventing these log errors and ensuring accurate RAID status.
PAN-335037
(All firewalls and panorama deployments that include syslog clients in logrcvr/logd) Fixed an issue where traffic logs were not forwarded to CloudWatch. With this fix, traffic logs are forwarded as expected.
PAN-334304
Few configs which pushed from SCM to firewall were causing the firewall to loose its internet connectivity and the firewall wasn't able to connect to cloud and was getting stuck at discovery stage retrying indefinitely without returning failure. And now ACR performs the the config rollback once the 5 cloud connectivity check attempts failed.
PAN-332389
Fixed an issue where a RAID array could not be rebuilt after a disk replacement because the data copy operation timed out. With this fix, RAID array rebuild operations complete successfully.
PAN-331617
Fixed an issue where traffic for certain websites was incorrectly matched to a security policy, preventing access for users when using specific web browsers, which occurred because the firewall used a generic session category for policy matching. With this fix, traffic correctly matches the intended security policy.
PAN-331387
Fixed an issue where IPsec tunnels frequently went down due to high process memory utilization. With this fix, the system process now manages memory correctly, preventing tunnel instability.
PAN-330876
Fixed an issue where auto-commit operations would fail during boot-up or after a reboot. With this fix, auto-commit operations complete as expected.
PAN-330196
Fixed an issue where the firewall unexpectedly terminated operations and rebooted due to an internal software error.
PAN-329034
Fixed an intermittent issue where firewall restarted unexpectedly while processing zip files.
PAN-328742
Fixed an issue where the dataplane silently dropped HTTP POST payloads, which disrupted application integrations. This occurred due to an internal error when processing XFF headers within the CTD engine.
PAN-326424
Fixed an issue where high memory utilization occurred in the escd process. With this fix, memory utilization for the process remained stable.
PAN-323154
Fixed an issue where Real-time Transport Protocol (RTP) packets were dropped after an upgrade, which occurred due to a predict session conversion failure and resulted in delayed or absent video streams. With this fix, RTP packets are processed correctly, and video streams display without delay.
PAN-317614
Fixed an issue where high throughput and increased packet rates caused high dataplane CPU usage.
PAN-313036
Fixed an issue where the firewall dataplane continuously accumulated packets in the ctd_pkt_queue and packet buffers, which caused resource exhaustion and prematurely terminated sessions.
PAN-309960
Fixed an issue where a memory leak related to the useridd process on the passive device led to an OOM condition.
PAN-283774
Fixed an issue where the firewall placed UDP sessions into a Discard state when a DNS Sinkhole/Block action occurred, which prevented subsequent DNS requests from reusing the same session and caused DNS-related outages.
