PAN-340201
Fixed a timing issue that caused the Ethernet/HSCI port to remain in a DOWN state after a physical fiber reconnection or system reboot. The port now properly recovers to an UP state after the fix.
PAN-342422
Fixed an issue where the Simple Network Management Protocol (SNMP) daemon would remain in a stopped state, which prevented SNMP polling capabilities. This occurred when specific non-ASCII characters were present in the SNMP configuration fields, which led to an error when the firewall processed the configuration. With this fix, the SNMP daemon now starts as expected, ensuring proper SNMP functionality.
PAN-343799
Fixed an issue where PA-3200, PA-5200, and PA-7000 Series firewalls repeatedly restarted data plane processes and became non-functional, which caused HA failover loops. This occurred when the firewall processed traffic on IPsec tunnels with anti-replay enabled.
