PAN-337475
(PA-5440 firewalls only) Fixed an issue where SaaS applications were incorrectly blocked even when a higher-order security rule should have allowed the traffic, which occurred due to an unexpected policy rematch behavior. With this fix, security policy rules are correctly applied during policy rematch, ensuring expected traffic flow.
PAN-337127
(Virtual machine firewalls only) Fixed an issue where virtual machine (VM) firewalls entered maintenance mode after a PAN-OS® upgrade, which occurred due to an erroneous software integrity test failure. With this fix, VM firewalls no longer incorrectly entered maintenance mode after an upgrade.
PAN-331498
Fixed an issue where a newly deployed firewall or a firewall after a factory reset had PAE disabled by default. With this fix, PAE is correctly enabled by default in these scenarios.
