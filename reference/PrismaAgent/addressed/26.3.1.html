PANG-14469
Fixed an issue on Windows endpoints where Endpoint DLP did not upgrade automatically after upgrading the Prisma Agent to version 26.3.0.x. Endpoint DLP remained on the previously installed version rather than upgrading to the bundled version. This issue affected upgrade scenarios only; fresh installations were not affected. Endpoint DLP now upgrades correctly as part of the agent upgrade process.
PANG-14273
Fixed an issue where connecting to the Endpoint Manager briefly displayed a "maximum allowed users reached" notification, even when the user limit had not been reached. When this occurred, the Prisma Agent entered a "Connecting" state that persisted for 10 or more minutes, the disconnect option became unavailable, and a subsequent connection attempt or device restart was required to establish connectivity. The agent now correctly interprets endpoint manager responses and only displays the user limit notification when the Endpoint Manager explicitly reports that the maximum number of users has been reached.
